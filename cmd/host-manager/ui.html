Codex Bridge 宿主管理器

首次安装与配对只需在此完成。随后从 Aide 插件工作台操作，无需终端。/ Install and pair once, then manage from Aide without a shell.

1 · 安装与运行 / Host lifecycle

需要本机 Node.js 18+ 和已登录的 Codex CLI。旧终端启动的桥接需先关闭一次；管理器不会终止外部进程。/ Existing external bridges must be closed once.



2 · 插件配对 / Pair Aide plugin
在 Aide → Codex Bridge → 设置中填写“管理地址”和下面的“管理密钥”。管理密钥允许本机固定生命周期操作，请勿填到模型提供商或聊天。/ The manager key controls lifecycle actions, not inference.
Docker Desktop: http://host.docker.internal:8788
Native: http://127.0.0.1:8788


3 · 模型提供商 / Model provider
模型 API 使用不同的密钥。安装宿主组件后可在此复制并填入 Aide 提供商设置；不会自动覆盖现有提供商。/ Provider setup is separate and never automatic.
